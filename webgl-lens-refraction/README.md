# Alpine Refraction

A WebGL page of mountain photos with a cursor-driven refraction lens. Layout stays in HTML/CSS; `@14islands/r3f-scroll-rig` tracks those blocks and draws them on a Three.js canvas.

Inspired by [Progressively Enhanced WebGL Lens Refraction](https://tympanus.net/codrops/2023/10/10/progressively-enhanced-webgl-lens-refraction/) (14islands / Codrops).

Stack: React 19, Vite, React Three Fiber, Drei, r3f-scroll-rig.

```bash
npm install
npm run dev
```

Photos from [Unsplash](https://unsplash.com/license). Fonts: Poppins and Playfair Display (SIL OFL 1.1).
